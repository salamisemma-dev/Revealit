# Reveal It

Dutch concept website based on Website behoeftes.pdf. Humanitas copy principles, BOB executable contracts, and 10K PremiumStudio art direction are applied to the host-supported Vinext starter.

## Routes
Home, Reveal Fit, Foundation, ANBI publication structure, contact draft preparation, privacy.

## Validation
- python3 scripts/bob_ready.py .
- node --test tests/message.test.mjs
- node node_modules/typescript/bin/tsc --noEmit
- node /root/.codex/plugins/cache/openai-curated-remote/sites/0.1.56/scripts/build-site.mjs

See delivery.md for actual results and limitations. Client scope and assumptions live under projects/reveal-it; semantic contract under specs.

## Launch dependencies
Original logo and photography; actual contact recipient and privacy particulars; prices, timetable and booking flow; product catalogue and merchant/payment configuration; verified foundation registration and documents; actual projects and impact evidence. Current form prepares a local draft only and transmits nothing.
